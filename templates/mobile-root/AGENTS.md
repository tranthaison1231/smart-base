# Agent Instructions

This is a product-neutral Expo Router starter. Keep mobile UI and navigation in `apps/mobile`.
Keep credentials and server-only operations out of the app; validate external data and use
an authenticated, authorized HTTPS API for protected server behavior. Add behavior-focused
tests for runtime changes. Run `pnpm format`, `pnpm format:check`, `pnpm lint`,
`pnpm typecheck`, `pnpm test`, and `pnpm build` before finishing.
